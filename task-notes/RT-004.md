## Integration review corrections (fail-closed gaps)

All five gaps from the integration review are fixed, with adversarial tests.
Verified by reverting each fix in turn and confirming the covering tests fail.

1. **Budget/timeout/identity bound to the protocol.** `warm_blocks=128`,
   `timeout_s=600` and `architecture_id` are read from `predeclared.json`, not
   from the run's exit status. A coherently rewritten budget (rows and exit
   status together) is now rejected.
2. **Exact rates.** Rate/block must be exact integers; `48000.5` no longer
   truncates into the valid `48000` key.
3. **Overflow retained, aggregates checked.** `cold_alloc_overflow` /
   `cold_lock_overflow` are no longer discarded: they are kept per row and any
   capture overflow blocks `measured-clean`. `warm_alloc_cxx_total` must be at
   least the visible C++ sum (extra nothrow/aligned `new` is legitimate and
   preserved) and `warm_alloc_c_total` must equal the visible C sum, so a
   positive per-kind count cannot be hidden by an inconsistent aggregate.
4. **Mandatory pin + real archive hashing + preflight.** The RT-003
   `source-pin.txt` is required, and the actual NAM and shared archives on disk
   are hashed against the predeclared identity (including the shared archive
   path from the pin file). `run_nam_arch.sh` now runs a preflight before any
   probe process and exits 2 without measuring on an invalid variant, changed
   budget, changed timeout, or any binary/archive/pin/model/source mismatch.
5. **Consistent schema validation + drum witness.** Malformed nested JSON
   shapes (list/null/scalar, wrong types) raise `Failed` rather than an uncaught
   `AttributeError`. A `drums=playing` row with no drum-bus activity is a
   missing witness, not clean; active blocks and voice events are bounded.

Evidence impact: none. The ten historical runs, raw CSVs, logs and findings are
byte-identical; still 7 measured-clean and 3 measured-findings, with the
A2/WaveNet positive allocations preserved. Only the derived summary files were
regenerated. `summary.md` gains capture-overflow and drum-witness columns.

Test count corrected: **81 tests = 13 evidence + 68 fixture/adversarial**
(the previous "36 = 10 + 26" was wrong on both numbers).
