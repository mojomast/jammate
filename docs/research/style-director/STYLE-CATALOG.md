# Style catalog (STYLE-001)

`src/jam/StyleCatalog.{h,cpp}` — a JUCE-free, bounded overlay of the compiled
drum library (`src/DrumLibrary.cpp`). DEVPLAN STYLE-001, SPEC.md 13.

## What a style is

The library is a warehouse of 570 anonymous one-bar patterns. A style names the
musical role of a subset: low/medium/high grooves, short/long/transition fills,
supported meter, BPM band, swing range, humanization defaults and an
anti-repetition distance. The Jam Director selects through this layer.

## Six shipped styles

Flagship UI order is fixed by the integration contract and frozen by
`stylecatalog.styleOrderMatchesUiContract`:

| Index | `StyleId` | Display | BPM min/ideal/max | Default swing |
|---|---|---|---|---|
| 0 | `Rock` | Rock | 70 / 110 / 175 | 0.00 |
| 1 | `HardRockMetal` | Hard Rock / Metal | 60 / 140 / 250 | 0.00 |
| 2 | `Blues` | Blues | 55 / 100 / 150 | 0.55 |
| 3 | `Funk` | Funk | 70 / 100 / 160 | 0.15 |
| 4 | `Pop` | Pop | 60 / 115 / 170 | 0.00 |
| 5 | `Shuffle` | Shuffle | 55 / 100 / 150 | 0.55 |

All supported meters are 4/4 (the only meter the compiled patterns use and the
only one the engine currently prepares). Every tier and every fill role is
non-empty for every style. `minRepetitionDistanceBars` is **consumed** by the
Jam Director as the effective anti-repetition window. The BPM band and the
swing min/max are **advisory hints for UI/tuning only, not runtime clamps**: the
Musical Clock is the sole tempo authority and the director emits only
`defaultSwing01`.

## References are indices + provenance

`PatternProvenance` carries `index`, actual `genre`, actual `name`, actual
`fill` flag, FNV-1a 32 `specHash` and actual `meter`. The catalog never keys off
names because `(genre, name)` is not unique:

- `("FUNK","Linear funk")` is a **groove at index 63** and a **fill at index
  187** (different pattern, different kind).
- `("ROCK","Shuffle rock")` is index 9 (swing 45) and index 535 (swing 33).
- 16 `(genre, name)` pairs collide; 27 names repeat somewhere in the library.

## Validation

`StyleCatalog::validate(const ILibraryProbe&)` checks every shipped reference
against a probe and returns `CatalogValidation { ok, checked, issues,
firstIssues[] }`. It rejects: index absent, wrong groove/fill role, genre/name
mismatch, meter mismatch, `specHash` mismatch, and unsupported meter.

The probe is fed from a committed snapshot of the ACTUAL library generated by
`tools/style-catalog/`:

- `tools/style-catalog/style_catalog_provenance.py --check` re-parses
  `src/jam/StyleCatalog.cpp` and `src/DrumLibrary.cpp`, resolves every ref and
  compares the live sha256 of the library to `StyleCatalog::libraryFingerprint()`.
- `generated/StyleCatalogLibraryFixture.h` is that snapshot, included by
  `tests/jam/StyleCatalogTests.cpp`, which runs `validate()` so index drift is
  caught inside the portable test binary.

Frozen library fingerprint (sha256 of `src/DrumLibrary.cpp`):

```
68008b4b139750e337a6166f6881e5724eee577b196efd8f467bf9562153d636
```

## specHash

`patternSpecHash` is FNV-1a 32-bit with 32-bit wraparound (offset basis
`0x811C9DC5`, prime `0x01000193`) over the UTF-8 spec string. Known vectors:
`"" -> 0x811C9DC5`, `"abc" -> 0x1A47E90B`. The Python tool implements the same
routine.

## Public API

```cpp
enum class StyleId { Rock, HardRockMetal, Blues, Funk, Pop, Shuffle };
enum class GrooveTier { Low, Medium, High };
enum class FillKind { Short, Long, Transition };

struct PatternProvenance { LibraryIndex index; const char* genre; const char* name;
                           bool fill; std::uint32_t specHash; Meter meter; };
struct StyleDescriptor { /* bpm band, meters, grooves[3][N], fills[3][M],
                            humanize, swing range, minRepetitionDistanceBars */ };

class StyleCatalog {
    static int count();
    static const StyleDescriptor& style (StyleId);
    static const StyleDescriptor& styleAt (int);          // clamps to Rock
    static const char* styleName (StyleId);
    static bool findStyleByName (const char* shortName, StyleId&);
    static CatalogValidation validate (const ILibraryProbe&);
    static const char* libraryFingerprint();
};
```

## Limitations

- Only 4/4 is modelled; odd-meter METAL/WORLD patterns exist in the library but
  are deliberately not referenced until the engine prepares them.
- Fill role (short/long/transition) is a style-overlay decision; the library
  only carries a boolean `fill` flag.
- The catalog is a curated subset (106 distinct indices), not an exhaustive
  classification of all 570 entries.
- A library change requires re-running `--emit` and re-reviewing the selection;
  `--check` fails until then.
