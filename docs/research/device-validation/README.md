## What is measured vs unmeasured

| Class | Backing required | Where it is allowed |
|---|---|---|
| Physical round-trip latency | a recorded loop-back WAV, re-analysed from bytes with canonical params | `device-validation/latency/1.0` |
| Callback p50/p99, deadline misses, analysis overruns | a **parseable** `device-validation/receipt/1.0` carrying the same values | `play-trial` `callback`, gating |
| Play timing, dropouts, useful-lock window/time | a parseable receipt with the same values | `play-trial` timing/lock/dropouts, gating |
| Same values backed only by an unparseable file | recorded as `receipt-attested`; **never gates** | `play-trial` |
| Operator judgements (SPEC 20) | none; always `operator-report` | `play-trial` `judgements` |
| Device disconnect / channel change / silent / clipped input | a parseable receipt whose `metrics.functional.outcome` matches | `device-validation/functional/1.0` |

Only `instrumented-raw` values (parseable receipt, value and interface identity
re-checked) and clean recorded loop-back WAVs gate a release. Callback
measurements never establish physical monitoring latency.

## Identity and anti-fabrication rules

- Every record stores product (`Guitar Companion`), a 40-hex source git SHA,
  build kind, backend, driver, input/output device, sample rate, block frames and
  monitoring mode.
- Every raw file and receipt is stored with its sha256 and byte size and must be
  session-contained and relative; the validator re-hashes it from disk.
- The validator re-derives each latency from the WAV using canonical parameters
  (condition spec + session interface); an edited latency, rate, channel count,
  target, `valid`, `reasons` or `target_met` is rejected.
- A record's interface identity must match the session manifest exactly,
  including devices and monitoring.
- `synthetic: true` on the session forces every record out of every physical
  gate, even when the record's own flag is false.

play conditions. An empty matrix never passes.

## Local availability (factual)

`environment.json` (from `probe_environment.py`, read-only) records this machine:
no `/dev/snd`, no `/proc/asound/cards`, no PipeWire socket, and no
`arecord`/`aplay`/`pw-record`/`sox`/`aplay`; only `ffmpeg` is present. No audio
interface, ASIO driver or Windows host is available here, so **no physical
latency, play-trial or ASIO evidence was or could be produced**. No packages were
installed.
